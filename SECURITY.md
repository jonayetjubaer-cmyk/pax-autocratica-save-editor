# Security

## Official downloads

Only download `PaxSaveEditor.exe` from this repository's GitHub Releases page.
Verify the SHA-256 checksum before running it. Do not run copies from mirrors,
file-sharing sites, or third-party repackagers.

## Save safety

- Close Pax Autocratica before editing.
- The editor creates a backup before every write.
- Do not open save files obtained from untrusted sources.
- Keep a separate manual backup before editing an important playthrough.

## Reporting a problem

Open a GitHub issue with reproduction steps and the application version. Do not
attach a personal game save; describe the affected collection and field instead.
